3. Core Architecture Rules (Strict Separation of Concerns)
Never mix module responsibilities. BMesh generation in properties.py is strictly forbidden (prevents circular imports).
* __init__.py: Addon metadata, sub-module imports, and central registration loop.
* properties.py: Add-on PropertyGroup classes only.
* generators.py & core.py: 
  - Define functions accepting context and obj. 
  - Init `bm = bmesh.new()`. 
  - Extract properties. 
  - Apply vertex changes securely. 
  - End with `recalc_face_normals`, `to_mesh`, `data.update()`, and `bm.free()`.
* panels/: Append `layout.prop()` to boxes/rows. Pass the literal variable name (omit `text=` unless overriding).
* operators.py: Build action commands here (`LSD_OT_...`).
* Handler Discipline (core.py): Define all app handlers in `core.py`. Register safely: `if handler not in bpy.app.handlers.X: append(handler)`. Enforce `(scene, depsgraph)` signature.
* Propagative Guards: Use `core._prop_update_guard = True` (with try/finally block) during multi-bone editing to prevent recursive loops.

4.1 Timer-based Update Discipline (Mandatory)
Dispatch complex operations (mesh generation, rig updates) triggered from property updates via short-interval timers to avoid "read-only" context errors.
* Pattern: `bpy.app.timers.register(lambda: bpy.ops.prefix.operator_name(), first_interval=0.01)`
* Guard Check: Ensure the update guard is False before registering to prevent infinite loops.

4.2 Debugging and Console Discipline (Mandatory)
Use the System Console for error reporting during kinematics testing.
* Persistent Shell: Launch via `dev_tool.py` or `.bat` to keep stdout active.
* Informative Errors: Proactively log state changes and calculation results.
* Error Capture: Wrap timer-based operations in broad try/except blocks to log silent failures.

5. Procedural Safety Limitations
* Boolean Data Purging: Explicitly delete previous cutter geometry via `bpy.data.objects.remove()` before generating new shapes to prevent boolean z-fighting.
* Real Units: Spatial properties MUST include `unit='LENGTH'` in `bpy.props` for correct Blender 4.5.6+ scaling. Multiply by `obj.dimensions` for size cages.
* Vertex Welding: Always run `bmesh.ops.remove_doubles(bm, verts=bm.verts, dist=0.0001)` before finalizing procedural meshes to close seams.

6. Code Skeleton Standards (generators.py)
* Type Hinting: Mandatory for context and obj parameters.
* Data Extraction: Pull directly from the prefixed PropertyGroup.
* Memory Cycle: `bmesh.new()` must be paired with `bm.free()`.
